# CS-300
DSA: Analysis and Design 2026  
What was the problem you were solving in the projects for this course?  
The problem for these projects was deciding how to store, search, and sort course data in an efficient manner. I had to compare different data structures; vector, hash table, and binary search tree, to gain an understanding of the performance trade-offs. After which, I had to implement a working program that could load course data, organize it, and output the results in a sorted format. The program needed to be both functional and incorporate the mos t appropriate data structure for the job.  
How did you approach the problem? Consider why data structures are important to understand.  
I approached the problem by analyzing the theoretical runtime and memory characteristics of each data structure. I used Big-O notation to predict how each structure would behave as the dataset grew. I used this analysis to implement these decisions into project two. Data structures are important because they directly affect a program's performance. Choosing the wrong one can make a simple task slow or inefficient. By comparing insertion, search, and traversal operations, I was able to justify why certain structures were better suited for sorting and retrieving course information.  
How did you overcome any roadblocks you encountered while going through the activities or project?  
There were several roadblocks when implementing the sorting logic and ensuring the program handled input data correctly. These challenges were made easier to overcome by breaking the problem into smaller steps, testing each component individually, and then using debugging tools to trace issues. Careful testing and incremental development helped to avoid errors.  
How has your work on this project expanded your approach to designing software and developing programs?  
Working on these projects reinforced the importance of planning before coding. I learned to think about the problem in terms of data flow, structure responsibilities, and algorithmic efficiency. Instead of jumping straight into implementation, I now consider how different design choices will affect performance and maintainability. This experience strengthened my ability to design modular, scalable programs that can be extended or optimized in the future.
